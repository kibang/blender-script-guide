# 블렌더 스크립트 & 모델링 도우미 · Blender Script & Modeling Guide

**사이트 / Site:** https://kibang.github.io/blender-script-guide/

**한국어** — Blender 5.3에서 직접 실행해 검증한 bpy 스크립트 100개(줄 단위 코드 해설, 실행 전/후 화면 포함)와, 사진 한 장으로 모델링 계획을 세워 주는 도우미, 예제 45개(기본 모델링 vs 모디파이어), Shift+A 추가 메뉴 갤러리를 담은 정적 웹앱입니다. 한국어/영어 지원(`?lang=en`).

**English** — A static web app with 100 bpy scripts verified by running them in Blender 5.3 (line-by-line code walkthroughs, before/after screenshots), a photo-to-modeling-plan helper, 45 worked examples (plain modeling vs. modifiers) and a Shift+A add-menu gallery. Korean/English (`?lang=en`).

No build step: open `index.html` or serve the folder. The optional AI mode uses an API key you type in the browser; no key is stored in this repository.
